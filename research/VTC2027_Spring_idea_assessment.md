## 1. 推荐结论

**首选：未知干扰功率下，基于功率不确定性边缘化的扩散干扰消除。**

建议英文题目：**Uncertainty-Aware Diffusion Interference Cancellation for Semantic Communications with Unknown Interference Power**。

中文：**未知干扰功率下的不确定性感知扩散语义通信干扰消除**。

研究问题：ICDM 在具有干扰先验、但接收端没有真实 SINR 的情况下，如何恢复信号，并避免把不可靠的干扰强度估计当成确定事实？

推荐原因：有明确代码依据；能够冻结现有 JSCC 和两个 DiT；主要修改似然引导和评估协议；可以形成一个通信问题、一项推断方法、四组核心实验。它是值得优先验证的选题，尚不是已经证实有性能增益或确定具有录用竞争力的成果。

## 2. 原论文究竟做了什么

阅读轴：实现与研究选题 / 完整论文 / 无线通信 / 方法、实验、局限、可复现性 / 深度阅读。

论文：Tong Wu 等，IEEE JSAC, vol. 44, pp. 2528–2543, 2026，DOI 10.1109/JSAC.2025.3643396。阅读对象是用户提供的 16 页正式版，不能只依据 2025 年 arXiv 初稿判断其未覆盖内容。

### 核心链路

图像 → JSCC 编码特征 → 信道、干扰及噪声 → 均衡 → ICDM 联合恢复信号和干扰 → JSCC 解码。

实数模型为

\[
y=\sqrt{P_x}W_xx+\sqrt{P_z}W_zz+W_nn.
\]

其中干扰链路系数被吸收到 z 内；接收端不要求知道干扰链路的瞬时 CSI。两个独立扩散模型分别学习信号先验和干扰先验，再通过同一个观测似然耦合，使用 p-ConJPC 迭代恢复。

必须区分三个概念：不知道干扰的实时内容；不知道干扰功率；完全没有相应干扰分布的训练样本。原文的“unknown/unaware interference”并不意味着三者均已解决：它明确要求独立训练干扰先验，并使用干扰样本集合。

### 真正可利用的缺口

1. **干扰强度侧信息依赖。** 公式需要 Pz，代码进一步使用真实 SINR 选引导参数。移除这种依赖是明确的接收端研究问题。
2. **中间时刻的似然是近似模型。** 论文式 (34) 包含扩散不确定性，式 (36) 又简化了协方差。若要给多个功率假设分配概率，协方差及 Gaussian normalization 不能随意忽略。
3. **连续干扰和单一匹配先验。** 论文系统模型明确描述同维度、连续影响信号的干扰；突发占用和先验失配值得研究，但工作量更大。
4. **时延仍很高。** 1.57 秒不能直接支持低时延车载实时主张；低时延研究应同时检查质量和实际端到端耗时。

理论阅读提醒：原文将 log-prior 的局部强凸性与高密度最优点联系，且从 Langevin 后验采样推向 MAP 最优点，这些论证需要单独核对符号和条件。新论文宜证明自己的局部恒等式或算法性质，不应直接继承“扩散采样保证得到 MAP”或全局精确恢复的结论。

### 不能算作创新的基线修正

- **幅度与功率的平方根位置。** `channel.inf_forward` 使用 Pz=10^(-SINR/10)-10^(-SNR/10)，但采样器 Ap 写成 sqrt(10^(-SINR/10))-10^(-SNR/10)。按该模型应是 sqrt(Pz)。SNR=SINR 时前者仍可非零。这一差异必须核验，并同时应用于所有可比算法。
- **均衡系数。** `Diffusion/Train.py:358` 的分母含 `2*sigma_square`，采样器使用 `sigma_square`，另一路 JSCC 评估也使用后者。需统一复数噪声功率与每个实维方差的定义。
- **Rayleigh 干扰先验训练。** `DiT/gaussian_diffusion.py:237` 附近对复高斯量先取平方根再除 sqrt(2)，与 `channel.py` 直接生成 CN(0,1) 信道不同。需要确认现有权重究竟由哪个版本训练；不能改训练分布后仍声称旧权重完全匹配。
- **运行脚手架。** 当前目录没有根级训练入口、依赖清单或根级 `utils.py`，但多处使用 `from utils import *`。`Diffusion/utils.py` 的存在不自动解决根目录 import。数据集与 checkpoint 路径写死为作者的 `/mnt/sda/...`；恢复 checkpoint 的 `isspace()` 条件也需核验。
- **评估样本数。** 两个 loader 使用 zip，实际只遍历较短者。应明确图像数量、干扰配对方式和随机种子。

这些是静态核查发现；尚未运行用户 GPU 环境，因此不代表用户手头的可运行版本一定具有全部问题。应保留原始版本记录，并另建立统一核验后的基线。代码修复收益不能作为论文的方法收益。

## 4. 推荐方法：边缘化干扰功率，而非提前认定单一估计

### 4.1 最小问题设定

令 A=√Px Wx，B=Wz，a=√Pz≥0，使用

\[
y=Ax+aBz+n_e,\qquad n_e\sim\mathcal N(0,C_n).
\]

保留期望信号 CSI、噪声功率、已有信号先验和已有干扰先验，只把干扰幅度 a 当成未知量。z 的分布尺度由预训练与标准化约定固定，避免 a 与 z 的任意缩放。Rayleigh 下 z 已包括干扰链路，不再额外重复估计其瞬时增益。

这是“未知干扰功率”问题，不是完全盲接收机，更不是对所有未知干扰分布都有效的保证。

### 4.2 核心想法

点估计方法先求一个 a_hat，再像它完全准确一样执行消除。当 a_hat 不可靠时，这可能使期望信号被错误地解释为干扰。

研究方案改为

\[
p(x,z\mid y)\propto p_x(x)p_z(z)\int_0^\infty p(y\mid x,z,a)p(a)\,da.
\]

保留多个合理干扰强度及其概率，按概率组合似然梯度。网络依然学习原来的两个先验，增加的是一个低维参数的积分。

### 4.3 一条可证明且可解释的恒等式

在干净变量空间，记 r=y-Ax、u=Bz，m=E[a|x,z,y]、s2=E[a²|x,z,y]。由对积分求导可得

\[
g_x=A^\top C_n^{-1}(r-mu),
\]

\[
g_z=B^\top C_n^{-1}(mr-s2\,u).
\]

若只把后验均值 m 代回普通引导，则第二式把 s2 错当成 m²，漏掉

\[
-\operatorname{Var}(a\mid x,z,y)B^\top C_n^{-1}Bz.
\]

这一项解释了“不确定性”为什么不只是给功率点估计起一个新名字。它不保证最终图像指标一定更优；效果依赖先验、可辨识性和中间时刻近似。

本次用 8 维线性 Gaussian 观测和 129 个积分节点做中心差分核对：两组梯度最大绝对误差分别约 4.15e-11 和 4.26e-11。这只验证代数实现，绝不代表通信性能结果。

### 4.4 如何接到扩散中间时刻

不能直接把干净变量恒等式套到 x_t、z_t。原文式 (34) 提供了 Gaussian 似然近似方向，但其缩放和简化不能未经核对直接沿用。

以标准前向过程 x_t=√αbar_t x0+√(1-αbar_t)ε 为记号。采用仅用于似然近似的零均值 Gaussian 先验，方差为 τx²，则

\[
c_{x,t}=\frac{\sqrt{\bar\alpha_t}\tau_x^2}{\bar\alpha_t\tau_x^2+1-\bar\alpha_t},
\qquad
v_{x,t}=\frac{\tau_x^2(1-\bar\alpha_t)}{\bar\alpha_t\tau_x^2+1-\bar\alpha_t}.
\]

z 同理。这些 Gaussian 量只近似条件似然；用于采样的主先验仍来自现有 DiT。τx²、τz²由训练/验证特征的尺度确定，不能从测试真值调节。

得到代理似然

\[
\widetilde p_t(y\mid x_t,z_t,a)=\mathcal N\left(y;
c_{x,t}Ax_t+a c_{z,t}Bz_t,\ C_t(a)\right),
\]

\[
C_t(a)=C_n+v_{x,t}AA^\top+a^2v_{z,t}BB^\top.
\]

保留 a 对协方差的影响。选择 Q 个幅度节点 a_q 及固定先验积分权重 π_q，计算

\[
w_{q,t}=\operatorname{softmax}_q\left[
\log\pi_q-\tfrac12 r_{q,t}^\top C_t(a_q)^{-1}r_{q,t}
-\tfrac12\log\det C_t(a_q)\right].
\]

其中 r_q,t=y-cx,t Axt-aq cz,t Bzt。混合引导为

\[
g_{x,t}=\sum_qw_{q,t}c_{x,t}A^\top C_t(a_q)^{-1}r_{q,t},
\]

\[
g_{z,t}=\sum_qw_{q,t}a_qc_{z,t}B^\top C_t(a_q)^{-1}r_{q,t}.
\]

在当前 AWGN / 逐符号 Rayleigh 的算子结构下，相关协方差可按对角或小块结构处理。多个节点共享同一次信号/干扰网络预测，新增的是约 O(Qd) 的代数运算，不是运行 Q 条完整扩散链。实际时延仍需测量。

这套中间时刻公式也做了中心差分核对，最大绝对误差约 9.04e-11。它是上述 Gaussian 代理似然的正确梯度，不是对真实非 Gaussian 扩散后验精确性的证明。

### 4.5 最小实现约束

1. 首轮使用单帧共享幅度，Q=9/17/33 做积分精度消融；节点范围和先验在验证集上固定，不能围着真实测试 SINR 放节点。
2. 每个时刻从同一个幅度先验重算权重；不要把同一个观测的 likelihood 在 40 步里反复当成 40 次独立观测相乘。
3. 不允许新算法读取真实 SINR 来选 Lambda/Beta、积分区间、早停阈值或方法分支。可以保留全局校准系数，但在验证集固定且如实报告。
4. 记录幅度后验均值、方差、边界概率及有效节点数，检测不恰当的后验过早集中。
5. 先维持原有 40 步和骨干。功率边缘化、协方差恢复、采样加速不能混在一次比较里。
6. 若 a 与 z 的尺度区分不稳定，先检查预训练特征尺度与信道统计；只有确需额外参考符号时才加短导频，并报告其通信开销。

## 5. 文献定位：贡献必须窄而准确

本次对 ICDM 做全文与代码阅读；以下外部研究主要完成摘要/方法定位，不能当作穷尽式查新或所有全文已深读。

| 已有工作 | 已解决的问题 | 对本题的边界 |
|---|---|---|
| [Removing Structured Noise using Diffusion Models, TMLR 2025](https://tristan-deep.github.io/publications/diffusion/diffusion_paper/) | 信号与结构化噪声的双先验联合扩散 | 双网络、双先验不构成新意；该工作也被 ICDM 引用 |
| [GibbsDDRM, ICML 2023](https://proceedings.mlr.press/v202/murata23a.html) | 预训练扩散先验与未知线性算子的联合恢复 | “扩散+盲参数估计”不是首次；普通交替更新应做基线 |
| [Listening to the Noise / GDiff, ICML 2024](https://arxiv.org/abs/2402.19455) | 未知参数化 Gaussian 噪声的信号/噪声参数联合推断 | “未知噪声强度”也已有；需突出结构化干扰双先验及低成本幅度积分 |
| [SIC-aided diffusion for joint channel estimation and data detection](https://arxiv.org/abs/2501.11229) | 低秩多用户系统的联合信道和数据估计 | 不宜泛称首次联合信道估计与扩散干扰消除 |
| [Enhanced OMDMA with shuffling and diffusion](https://arxiv.org/abs/2507.20477) | 特征置乱、多用户干扰 Gaussian 化与扩散去噪 | “扩展成多用户+扩散”过宽；其协作/发射端假设与本题不同 |

适合写成的贡献：

- 定义并验证现有 ICDM 对干扰功率侧信息的敏感性，建立移除真实 SINR 的公平接收协议。
- 推导幅度不确定性边缘化后的联合引导，说明点估计遗漏的二阶项，并使用含扩散不确定性的代理似然实现低维积分。
- 在相同预训练网络和网络评估次数下，验证未知功率恢复、初值敏感性与质量/时延开销。

不应写：首次使用双扩散先验；首次用扩散做盲估计；完全无需干扰先验；保证 MAP 收敛；适应任意未知干扰；未经测量的实时车联网。

## 6. 最小实验矩阵与判定标准

### 6.1 必需基线

| 基线 | 接收端可用信息 | 用途 |
|---|---|---|
| JSCC + 常规均衡 | 同等 CSI/噪声信息 | 无消除参照 |
| 核验后的 ICDM，真实功率与原查表参数 | 额外真实 SINR | 有利侧信息参考，不是数学性能上界 |
| ICDM + 有偏/陈旧功率 | 不正确的功率值 | 暴露部署问题 |
| ICDM + 简单能量法功率估计 | 仅观测与同等先验信息 | 排除“估一下功率就够了” |
| ICDM + 交替加权最小二乘幅度更新 | 同等信息与网络预算 | 排除普通点估计就能解释收益 |
| 本方案，功率点估计版本 | 同一代理似然，取均值/MAP 节点 | 验证保留不确定性是否有独立价值 |
| 本方案，完整幅度边缘化 | 同等信息 | 目标方法 |

固定 x,z 时，交替最小二乘基线为 a_hat=max(0,uᵀCn⁻¹r/(uᵀCn⁻¹u+ε))；它不是新贡献。对该基线也使用尺度约束、合理更新时机和独立验证，不能故意采用差初值。

AWGN 且信号/干扰单位复功率时，简单能量基线为 Pz_hat=max(mean|y|²-Px-σ²,0)。它依赖独立性、尺度和足够样本；Rayleigh/均衡后必须扣除正确的信号和噪声协方差贡献。它在长块上可能已经很好，这是首轮必须验证的否决风险。

### 6.2 四组核心图

1. **功率失配曲线。** 固定真实 SINR=0 dB，偏差 Δ∈{-6,-3,0,3,6} dB，并增加无外部 SINR 输入的模式。横轴明确是功率先验/输入估计的误差。
2. **未知功率性能曲线。** 第一轮 SNR=20 dB，真实 SINR∈{-4,0,4,7} dB；随后加 10 dB SNR 核查。真实值仅供信道生成与画图，不能传给目标接收机。
3. **不确定性与消融。** 完整协方差/简化协方差 × 点估计/边缘化，配上幅度误差与后验宽度。增加“已知幅度+完整协方差”，区分两个模块的收益来源。
4. **质量与开销。** Q=9/17/33，必要时 20/40 步；报告 LPIPS、latent NMSE、PSNR、网络调用次数、峰值显存、采样及端到端时延。

先跑已经有匹配权重的单数据集和单骨干；优先 AWGN 排除尺度/信道实现问题，再扩到 Rayleigh。第二数据集只在具有匹配权重时加入。不要为凑实验把新数据直接喂给分布不匹配的先验，然后误称跨数据集泛化。

统一随机图像/干扰配对、信道噪声和扩散初始噪声，做 paired comparison。首轮用 64–128 对筛选，正式结果建议至少 500 对、3 组随机种子，并对逐图像差值做 bootstrap 置信区间。图像较少时必须报告数量与区间，不能把同一图像多次噪声试验当成完全独立图像。

### 6.3 提前否决规则

以下均是研究推进标准，不是承诺的实验结果：

- 若统一修正后 ICDM 对合理功率误差几乎不敏感，这条动机不足。
- 若简单能量法或普通交替估计与边缘化方法无稳定差异，不宜把“功率不确定性”作为核心卖点。
- 若只有恢复完整协方差有效，应重写选题为有理论支撑的似然校准，并重新评估创新是否足够。
- 若收益只来自测试 SINR 查表、更多网络调用或更强先验训练，实验不支持目标贡献。
- 若所有收益仅在一个极端点，无法支撑普适鲁棒主张。

## 7. 备选 idea 排序

| 排名 | Idea | 价值与主要风险 | 当前建议 |
|---|---|---|---|
| 1 | 未知功率与不确定性边缘化 | 切口清晰，复用权重；风险是简单估计器已足够 | 立即做小规模判别实验 |
| 2 | 分块突发干扰的活动概率感知 ICDM | 模型 y=Ax+aB(m⊙z)+n，m 在传输块上开/关；联合估计占用，避免干净块过消除 | 若已有突发仿真或主线动机弱，可转此方向 |
| 3 | 质量受约束的自适应计算预算 | 根据可观测残差/不确定性决定是否继续采样，验证质量与时延折中 | 适合作为后续；只用 SINR 阈值早停较弱 |
| 4 | 不完美 CSI 的后验边缘化/联合更新 | 高速链路问题重要，但原文已有 CSI 误差实验，且联合估计文献多 | 两周内不优先重建信道模型 |
| 5 | 未见干扰先验下的鲁棒混合先验 | 更接近开放环境；需要多个干扰族、OOD 测试和更长验证 | 更适合后续完整项目 |

突发备选的最小贡献应是“活动后验进入引导”，不是简单给干扰乘一个随机 mask。mask 应定义在传输顺序/资源块上，明确 I/Q 配对和特征映射。测试必须同时报告固定 active power 与固定平均干扰功率，避免占空比下降带来的自然 SINR 改善被误认成算法增益。

自适应步数备选应在相同平均网络调用次数下对比最优固定步数；联合问题中很小的观测残差不意味着 x,z 分离正确，不能单靠残差宣称语义可靠。需校准冻结解码器输出的质量代理并报告失败样本。

不建议此轮展开：端到端重训、DiT 换 Mamba、完整 OFDM+MIMO+Doppler、多用户联合调度与功率控制、一至四步蒸馏的全套系统。它们并非没有研究价值，而是与当前截止时间和可复用资源不匹配。
