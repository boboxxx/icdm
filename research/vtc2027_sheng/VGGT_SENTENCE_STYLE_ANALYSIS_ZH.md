# VGGT 语句结构分析及迁移规则

## 阅读对象

- J. Wang et al., “VGGT: Visual Geometry Grounded Transformer,” CVPR 2025, pp. 5294–5306.
- 官方全文：https://openaccess.thecvf.com/content/CVPR2025/html/Wang_VGGT_Visual_Geometry_Grounded_Transformer_CVPR_2025_paper.html
- Oxford 作者版：https://www.robots.ox.ac.uk/~vgg/publications/2025/Wang25/wang25.pdf

VGGT 是典型的计算机视觉方法论文。它围绕一个模型主张组织全文，并用基线比较、消融、下游任务和局限分析形成证据链。本文只迁移其信息组织和句法节奏，不复制原文措辞，也不把 VGGT 的研究主张写入 VTC 稿件。

## 主要语句结构

1. **先给动作，再给对象和范围。** 方法句通常以作者或具体模块作主语，谓语靠前，句尾承载输入范围、输出或结果。
2. **旧信息开头，新信息落在句尾。** 前一句引入对象，后一句继续使用该对象作话题，使段落主语稳定，读者不必重新定位。
3. **长句建立关系，短句落锤。** 说明句可包含一个从句；随后用短句给出关键判断、对比或范围限制。全文并非追求短句，而是控制每句只承担一个主要功能。
4. **转折句直接暴露矛盾。** 常见结构为“现有方法取得进展；然而仍依赖某项代价”，随后提出本文处理的具体问题。
5. **方法段采用总述—顺序—细节。** 节首先用一句话定义输入和输出，再用一句 roadmap 说明各小节顺序。小节内部通常按“定义—操作—作用”展开。
6. **实验段采用目的—协议—结果—解释。** 首句说明本实验验证什么；接着给数据、指标和公平设置；随后引用表图给结果；最后解释结果支持哪个主张以及不能推出什么。
7. **比较句让参照物保持可见。** 使用 `while`、`whereas`、`in contrast` 或 `compared with` 把基线和本文方法放在同一句或相邻两句中。
8. **限定语紧跟主张。** 数据域、推理模式、是否使用后处理等限制通常与数字一起出现，而不是集中到段末补救。
9. **结论只回收主张。** 结论依次重述方法、核心结果、与现有范式的区别和适用价值，不重新引入技术细节。

对 PDF 主文做近似分句统计后，方法部分句长中位数约为 21 个英文词，实验部分约为 18 个词。短句比例在实验部分更高，说明结果陈述比方法定义更紧凑。该统计受 PDF 断词和公式影响，只用于把握节奏，不作为硬性写作模板。

## 映射到 VTC 稿件

| VGGT 结构 | 本文对应写法 |
|---|---|
| 先声明模型及输入输出 | 摘要首句声明 blind selector，并立即说明它选择的两个接收机 |
| 传统范式—代价—研究问题 | 引言从固定 Gaussian/joint 接收机推进到逐帧扰动模型选择 |
| 节首总述与 roadmap | 第 II–IV 节均先说明本节输入、操作和输出顺序 |
| 定义—机制—作用 | 系统模型定义信道后解释观测和先验分别提供什么信息 |
| 目的—协议—结果—解释 | 每个实验小节先说明验证目标，再给比较、区间和科学边界 |
| 主张后立即限定 | PSNR 增益与确认总体、配对区间、单训练种子及协议差异相邻书写 |
| 简短结论 | 结论回收选择机制、质量/计算结果和失配风险 |

## 不迁移的部分

- 不使用 VGGT 的 3D 任务、模型规模、SOTA 结论或 foundation-model 定位。
- 不模仿其少数带宣传色彩的副词；本文保留配对区间和负结果。
- 不把外部 DeepJSCC/MambaJSCC 参照改写成与共享潜空间接收机完全公平的排名。
- 不增加尚未实验的信道、任务语义指标、联合功率分配或完整 CDDM/ICDM 复现主张。
